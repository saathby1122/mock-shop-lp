Frequently asked questions

How can I build an online store before I have products?

Point your storefront at mock.shop and build against a catalog that already exists. It serves real products, images, collections, variants and carts over an auth-free GraphQL API, so the whole shop can be built and reviewed before you have a single product of your own. When your real catalog is ready, swap the endpoint and the queries keep working.

Do I need a Shopify account or API key to use mock.shop?

No. mock.shop is auth-free: no account, no API key, no access token and no setup. The single exception is metafields, which need the header X-Shopify-Storefront-Access-Token: public, the same header a real store expects.

How do I choose a sample catalog for my store?

Pick the store whose products look like what you are selling. Every store describes its own catalog at https://<store>.mock.shop/llms.txt, so an agent can read the list and choose for you. The directory at https://mock.shop/llms.txt lists them all.

Can I use mock.shop with an AI coding tool?

Yes, and it is the fastest way in. Copy the prompt at the top of this page into Claude Code, Cursor, or any agent that can write files, and it will scaffold a storefront wired to mock.shop. Because there is no auth step, the agent can query the API and keep iterating on its own.

What can I test with mock.shop?

Anything that reads a storefront: product and collection pages, search and filtering, variant pickers, cart add, update and remove, and the hand-off to checkout. The endpoint mirrors the Shopify Storefront API, so what holds here still holds when the same queries point at a real store.
